## About Me

I’m a Full-Stack Developer focused on building reliable and maintainable web applications from backend architecture to frontend user experience and production deployment.

My primary stack is **Python, Django, Django REST Framework, Next.js, React, and TypeScript**. I enjoy designing RESTful APIs, authentication systems, database models, background processing workflows, and responsive user interfaces.

I also work with **PostgreSQL, MySQL, Redis, Celery, Docker, Nginx, and AWS** to build applications that are structured for scalability, performance, security, and maintainability.

I care about writing clean code, understanding how systems work, and solving real-world engineering problems rather than simply making features work.
